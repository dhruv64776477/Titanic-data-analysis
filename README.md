# Titanic Data Analysis

## Project Overview

This project focuses on cleaning, preprocessing, and exploring the Titanic passenger dataset using Python.
The goal is to understand the dataset, handle missing values, perform data preprocessing, and discover patterns related to passenger survival through Exploratory Data Analysis (EDA).

## Dataset

Source: Kaggle – Titanic: Machine Learning from Disaster

- File used: train.csv
- Records: 891 passengers
- Features: 12 columns
